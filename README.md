## Featured Projects

### SourceUp — Explainable Supplier Recommendation System
> *Sentence-BERT · FAISS · LightGBM LambdaRank · SHAP · FastAPI · Java/Selenium*

Final-year capstone. Ingested 1M+ records via Java/Selenium pipeline → semantic search via Sentence-BERT + FAISS → constraint-aware LTR ranking (price, delivery, reliability) → SHAP explainability layer for procurement decision support.

---

### CareerGenie — AI Career Intelligence Platform
> *FastAPI · React · ChromaDB · LLaMA 3.2 · BPR-LTR · Multi-Agent*

**Best Industry Innovation Award — Industry Innovation '26 (National, 63+ teams)**

RAG-based resume-to-job matching with MiniLM embeddings, BPR learning-to-rank for personalized recommendations, and a multi-agent propose→critique→synthesize loop to reduce hallucinations. Full-stack platform with ATS scoring, mock interview generation, and confidence badges.

---

### MonoSplat — Single-Video 3D Reconstruction Pipeline
> *PyTorch · FastAPI · COLMAP · FFmpeg · Three.js*

Converts RGB video into interactive 3D Gaussian Splat scenes viewable in browser. SfM-based camera pose estimation via COLMAP, GPU-accelerated Gaussian training on Colab, async FastAPI job pipeline. Achieves 30+ FPS real-time rendering.

---

### FinGuard Pro — Real-Time Financial Fraud Detection
> *XGBoost · SHAP · FastAPI · Streamlit · SQL*

**Published — ICAAIC 2025 (ISBN: 979-8-3315-6587-9)**

94% recall · ROC-AUC 0.995 on imbalanced financial data. Role-based dashboards, SHAP audit trails for explainable decisions, and automated PDF/ZIP reporting pipelines for compliance-ready fraud investigation workflows.

---

### IntelliGrade-H — AI Handwritten Exam Grader
> *FastAPI · Streamlit · Google Cloud Vision · Mistral · PaddleOCR · Groq · Claude*

Multi-OCR cascade (GCV → Mistral → Azure → PaddleOCR → Tesseract → TrOCR) with LLM grading chain (Groq → Claude fallback). Handles institution-specific paper formats including shared preamble blocks, CID font decoding, and handwritten option correction mappings.

---

### S.A.F.E — Real-Time Crowd Anomaly Detection
> *OpenCV · Farneback Optical Flow · MAD · FastAPI · Streamlit*

Privacy-preserving anomaly detection for CCTV via optical flow aggregation. Global motion compensation reduced false positives by 40–60%. ROC-AUC 0.8391 on cross-domain datasets without retraining.

---

### Redline — Multilingual Preventive Healthcare Chatbot
> *IndicBERT · Groq LLaMA 3.3 · FastAPI · Telegram API*

**Smart India Hackathon 2025**

IndicBERT intent classifier with LLM fallback for 10+ Indian languages. 82.4% intent accuracy, 95.6% safety filtering. Real-time regional health alerts via Telegram.
